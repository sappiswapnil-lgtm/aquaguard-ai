# AquaGuard AI

A standalone, responsive hackathon website inspired by the AquaGuard AI early-warning concept at `sink-alert.lovable.app`.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/root`.
5. Save. GitHub Pages will publish the site.

No build step, npm, API key, database or backend is required for this demo version.

## Included
- Responsive landing page
- Public dashboard
- Geographic heatmap demo
- Early warning center
- Explainable risk scoring
- Analytics
- Anonymous report form
- Water quality dashboard
- Authority demo
- Interactive modals, filters and status controls
- Synthetic demo data

This is a front-end prototype using synthetic data and is not a medical diagnostic system.
